# Proposals (RFCs)

Design proposals owned by `@rak200/ui`. A proposal is first and foremost a place to **study**: state
an intention, research how the problem is solved elsewhere, sketch a design that fits, and only then
decide.

The process — the steps, the statuses, the template — is `.rak200/proposals/README.md`, and the
numbering here is this repository's own. A proposal that spawns work in another repository, or that
descends from one written elsewhere, is joined to it by mother↔daughter links.
