RFC 0004 — a catalogue of effects, per component and per moment

One page per component. Each renders the real component from src/, offers the effects the proposal would ship for each moment it answers, and lets you choose one per moment at four scopes — the page, a region, every instance of the component, or one instance. The choice is a custom property; the component reads it with a style query on its own shadow root. The last page sets every component side by side, to compare one moment from one to the next.
