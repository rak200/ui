Default: the accent a host picks, and the label that follows it

Pick an accent. Today the label on it is a ground of its own — white in the light scheme, #111827 in the dark — so a host who moves the accent has to move the label as well, and nothing reads the pair. Proposed is question 3: the label is the WCAG pole of the accent, and the hover and pressed shades mix away from it. The same accent goes to both schemes, as it would from a host setting one value.

Hover and press the primary buttons to see the shades. The floors under each panel are read in this browser with the suite's own ratio — and they show what the proposal does not solve: the label holds on every accent, but the accent's own hover and pressed states can stop being visible. Yellow shows it in both columns: a very bright accent has no room left toward white, and a very dark one none toward black.
