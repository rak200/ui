High contrast: the reader's setting, not a theme

Question 4's recommendation. When the reader's system asks for more contrast, the default palette moves its text to the pole — black in the light scheme, white in the dark — and nothing else. The border, the muted text, the hover and the striped row all mix toward the text, so each rises with it. The surface stays where it is, so the dark scheme keeps a visible hover.

What does not rise is every colour that is a ground of its own: the label on the accent and the three outcome colours. The floors below show both.

The right-hand panels are a stand-in. To try the media query itself, open DevTools → Rendering → Emulate CSS media feature prefers-contrast → more: the left-hand panels then become the right-hand ones.
