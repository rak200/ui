Matrix: a green that glows, on black and on white

Both schemes: the reference's bright green on black, and a dark green on white — switch between them at the top. The glow on the raised surfaces is the elevation step set to a glow, with no new name (question 2); only its colour changes with the scheme. Matrix used to be the one theme that declined a scheme, so question 5 no longer has a case among the four.

Where the reference loses to a floor. It draws its boundary at #003300, which is 1.43:1 against the ground; the derived border replaces it, because a control's boundary owes 3:1. The glow on text is not a token at all — toggle it below and decide whether a theme may carry it.

Where the proposal itself fails. The last panel is the same theme under today's formulas: its accent is the text's own green, and today the accent's hover mixes toward the text, so the hover does not move at all — 1.00. The proposed formulas move it toward whichever pole has room: a green this bright has almost none left toward white, so it darkens, toward its black label, which has room to spare — 1.43 in the dark scheme, where moving away from the label gave 1.03.

The glow can reach the controls too — buttons, fields and checks, each on its own toggle — which is where elevation is not read, and so where question 2 would need a name of its own, though not a value: it is the raised surfaces' ring and glow, the same colour at the same blur. A glow lights what sits beside a boundary, so the rows under each panel read a field's edge and a checked box against it. The page starts at the look chosen, the glow laid right against the edge, and there the ring takes a field's boundary well under 3:1; held 2px off the edge, the boundary keeps the surface it was chosen against. The slider sets the strength of every glow at once.

A button lights up under the pointer: its ring goes solid and its glow doubles, where the fills' own hovers barely move in this green. The row under each panel reads the ring at rest against the ring under the pointer.

An invalid field can write its value in red too, inside its red edge and glow; the danger row is that pair, since the field is filled with the surface.
